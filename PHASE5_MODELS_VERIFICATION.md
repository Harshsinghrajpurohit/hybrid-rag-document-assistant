### 4.1 RRF Score Generation (Verified from Code)

HybridRetriever._rrf_fusion() (lines 145-175):
```python
def _rrf_fusion(
    self,
    bm25_results: List[Tuple[str, float]],
    dense_results: List[Tuple[str, float]],
    k: int = 60,
) -> List[Tuple[str, float]]:
    """
    RRF formula: RRF_score(doc) = sum(1 / (k + rank) for each ranker)
    """
    rrf_scores = {}
    
    # BM25 contributions
    for rank, (doc_id, _) in enumerate(bm25_results, 1):
        rrf_scores[doc_id] = rrf_scores.get(doc_id, 0) + 1 / (k + rank)
    
    # Dense contributions
    for rank, (doc_id, _) in enumerate(dense_results, 1):
        rrf_scores[doc_id] = rrf_scores.get(doc_id, 0) + 1 / (k + rank)
    
    return sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)
```

SCORE CALCULATION:
- k = 60 (constant)
- rank = position in list (1-indexed)
- Per ranker: 1 / (60 + rank)

SCORE RANGE CALCULATION:
- Best case (rank=1): 1/(60+1) = 0.01639
- For two rankers (BM25 + dense):
  - Both rank 1: 0.01639 + 0.01639 = 0.03278
  - Typical top-5 only: ~0.03-0.05
  - Maximum practical: ~0.1

ACTUAL OUTPUT (from HybridRetriever.retrieve() line 262):
```python

```

def _calculate_confidence(self, scores: List[float]) -> float:
    if not scores:
        return 0.0
    
    avg_score = sum(scores) / len(scores)
    confidence = min(avg_score * 20, 1.0)  # Scale by 20x and cap at 1.0
    
    return float(confidence)
