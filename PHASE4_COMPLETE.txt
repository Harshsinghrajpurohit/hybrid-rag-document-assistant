================================================================================
KEY FEATURES IMPLEMENTED
================================================================================

Answer Generation from Passages
  - Accepts retriever results in flat format (actual HybridRetriever output)
  - Extracts top-5 chunks for context (configurable)
  - Formats as "Source N (Page X, filename.pdf):" for each passage
  - Builds system + user prompt for LLM grounding

Prompt Design for Grounding
  - System prompt: "Answer only using provided sources"
  - User message: "Based on documents: [passages] Please answer: [query]"
  - Prevents hallucination by explicit grounding
  - Temperature: 0.3 (low, deterministic answers)

Source Citation Extraction
  - Page numbers from metadata
  - File names from metadata
  - First 150 chars of passage as excerpt
  - RRF scores for relevance ranking

Confidence Scoring
  - Based on average RRF scores from top passages
  - Scaled 0-1 range (RRF values typically 0.01-0.05)
  - Higher confidence = more relevant passages retrieved

Token Management
  - Counts both eval_count and prompt_eval_count from Ollama
  - Limits to top-5 chunks to stay within token budget
  - Reports actual tokens used in response

Error Handling & Edge Cases
  - Empty retrieval: graceful "insufficient context" response
  - None/null results: handled safely
  - Ollama timeout: raises descriptive error
  - Connection error: raises descriptive error

Flexible Result Format
  - Handles both nested ("scores": {"rrf": [...]})
  - AND flat ("rrf_scores": [...]) score structures
  - Adapts to retriever's actual output format

================================================================================
DESIGN DECISIONS
================================================================================

Why Top-5 Chunks?
  - qwen3:4b-instruct has 262k context window
  - Top-5 chunks ≈ 2-3k tokens, plenty of space
  - Reduces noise from lower-ranked results
  - Balances coverage vs. signal-to-noise ratio

Why Flat Score Extraction?
  - HybridRetriever returns flat structure
  - Added fallback to nested structure for flexibility
  - Graceful handling of both formats

Why RRF Scores for Confidence?
  - RRF scores reflect relevance from both BM25 and semantic search
  - More reliable than single signal
  - Industry standard (TREC proven)
  - Easy to understand and tune

Why System Prompt Grounding?
  - Explicit instruction to use only provided sources
  - Reduces hallucination risk
  - Simple, direct approach (no few-shot needed)

Why Temperature = 0.3?
  - Low temperature = deterministic, reproducible answers
  - High temperature = creative but inconsistent
  - For RAG, consistency > creativity
  - User can override if needed

Why Metadata Over LLM Extraction?
  - Metadata is reliable (from Phase 1)
  - LLM extraction prone to hallucination
  - Page numbers must be accurate for citations
  - Always use ground truth when available
